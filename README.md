# ঢাকা রান (Dhaka Run)

ঢাকার রাস্তায় ৩ লেনের এন্ডলেস রানার। Kotlin + Jetpack Compose, কোনো ছবি বা সাউন্ড ফাইল ছাড়া (সব কোডে আঁকা)।

## কীভাবে খেলবেন
- বাঁ/ডানে সোয়াইপ: লেন বদল
- ওপরে সোয়াইপ: লাফ (গর্ত ও সিএনজি পার হতে)
- নিচে সোয়াইপ: স্লাইড (ঝুলন্ত তারের নিচ দিয়ে); লাফের মাঝে দিলে দ্রুত নামে
- রিকশা ও বাস লাফিয়ে পার হওয়া যায় না, লেন বদলাতে হবে
- ওপরে ডানের বোতাম বা ব্যাক বাটন: বিরতি

## ফিচার
- ৪টি অঞ্চল (প্রতি ~৪০ ইউনিট পর বদলায়): গুলশান, পুরান ঢাকা, সদরঘাট, গ্রামবাংলা
- বাধা: গর্ত, সিএনজি, ঝুলন্ত তার, রিকশা, বাস
- পাওয়ার-আপ: নীল M = চুম্বক, সবুজ S = ঢাল
- তাড়া: প্রথম ধাক্কায় রাগী দোকানদার তাড়া করে (১০ সেকেন্ড); তার মধ্যে আবার ধাক্কা খেলে গেম শেষ
- দোকান: চুম্বকের সময়, ঢাল দিয়ে শুরু, কয়েনের মান, ৫টি পোশাকের রং
- মিশন: কয়েন, স্কোর, পাওয়ার-আপ (শেষ হলে পুরস্কার, তারপর আরও কঠিন)
- হাই-স্কোর, কয়েন, আপগ্রেড ফোনে সেভ থাকে
- সাউন্ড (চালু/বন্ধ করা যায়), বিরতি, অ্যাপ ব্যাকগ্রাউন্ডে গেলে অটো-পজ

## APK বানানো

### ১) GitHub Actions (ফোন থেকে, কম্পিউটার ছাড়া)
1. প্রজেক্টটা একটা GitHub রিপোতে পুশ করুন (`main` ব্রাঞ্চ)
2. রিপোর Actions ট্যাবে "Build APK" চলবে (বা Run workflow চাপুন)
3. শেষ হলে Artifacts থেকে `DhakaRun-debug-apk` নামিয়ে ইনস্টল করুন

### ২) Termux / কম্পিউটারে
```
chmod +x gradlew
./gradlew assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`
(JDK 17 ও Android SDK লাগবে)

## ফাইল
- `Game.kt`: গেমের নিয়ম, বাধা তৈরি, সংঘর্ষ
- `Render.kt`: সব আঁকাজোকা (রাস্তা, বাধা, খেলোয়াড়, HUD)
- `UI.kt`: মেনু, দোকান, বিরতি, গেম ওভার
- `Store.kt`: সেভ ডেটা, মিশন, সাউন্ড
- `MainActivity.kt`: শুরু ও পূর্ণ স্ক্রিন
